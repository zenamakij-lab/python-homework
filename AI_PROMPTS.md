3. "Inspect the catalog list view and suggest improvements for search logic, queryset performance, and pagination correctness."

## Test generation prompts

5. "Write Django tests for cart behavior, order totals, and user manager validation using pytest and factory-boy."

## Documentation prompts

7. "Add docstrings to all Django views and class-based views in the bookstore app and keep the code readable for future maintenance."
8. "Write a README section for a Django bookstore project and include AI Usage with the exact prompts used."

## Review note

The prompts above were used to improve readability, test coverage, and maintainability of the project. Suggestions were checked against the existing codebase and only valid changes were applied.
